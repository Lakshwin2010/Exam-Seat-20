4. DETAILED BREAKDOWN OF OPTION 1:
--------------------------------------------------------------------------------
A. HOW IT WORKS UNDER THE HOOD:
- WhatsApp provides a secure web/app protocol:
    https://api.whatsapp.com/send?text=<URL_ENCODED_MESSAGE>
- On PC/Laptop: Opens WhatsApp Web in a new tab with the text filled in the composer.
- On Mobile/Tablet: Opens the WhatsApp application directly.
- The user selects the target class group and hits Send.

B. WHAT THE APPLICATION DOES AUTOMATICALLY:
- The allocator engine already knows:
  * Every student's home section (XI-A, XI-H, XII-G, etc.).
  * Exactly which room each student is assigned to (handling class splits).
  * Roll number ranges, student names, and desk numbers.
- The system compiles this into section-specific messages with school emojis and bold tags.

6. DISPATCH PDF EXPLANATION & ARCHITECTURE:
----------------------------------------------------------------------
A. WHAT IS THE "DISPATCH" DOCUMENT?
- "Class Outward Exam Despatch" is the document for each home class that lists
  where all students of that class must go on exam day.
- Columns:
  1. S.No
  2. Roll / Exam Number
  3. Student Name
  4. Gender
  5. Exam Subject
  6. Assigned Exam Hall / Room (e.g. Room XI-A, Room XII-A, Room XII-G)
  7. Desk / Seat Number (e.g. Desk 1A, Seat R1-C1)

B. WHY PDF IS PREFERRED OVER EXCEL:
- Parents and students view notices on mobile phones.
- Spreadsheets (.xlsx) are hard to read on mobile and require extra apps.
- PDF opens cleanly in 1 tap on any phone or browser.

C. HOW THE DISPATCH PDF WILL BE SHARED / SENT:
1. One-Click Quick Share to WhatsApp:
   - Click "Share Dispatch PDF to WhatsApp".
   - The app instantly downloads the clean Exam_Dispatch_<Section>.pdf.
   - The app opens WhatsApp Web with the section notice pre-typed.
   - User drags and drops the downloaded PDF into the group chat and presses send (takes ~2 seconds).
2. Direct Clickable PDF Link in the WhatsApp Message:
   - WhatsApp message text includes a direct link:
     "Download Official Seating PDF: http://<server>/api/reports/dispatch-pdf/<section>"
   - Any parent or student taps the link inside WhatsApp and the PDF opens instantly.
3. Automated Email Dispatch Attachment:
   - In the Email Class Sheets modal, attach the Dispatch PDF directly alongside the Excel workbook so teachers have the PDF in their inbox.

D. BACKEND IMPLEMENTATION PLAN:
- Engine: Python reportlab library (installed and verified in environment).
- Endpoint: GET /api/reports/dispatch-pdf/{section} with query param session_id.
- Output: Professional A4 PDF with table, school header, blue/emerald theme, and alternating row styling.
